# LuBo School — 塾運営支援システム

塾運営で分散しがちな情報（連絡・授業記録・欠席共有・相談・シフト・時間割など）を一元管理するための業務用 Web アプリケーションです。飯能教室での試験運用を想定しています。

Node.js 標準機能のみで動作し、外部パッケージのインストールやビルドは不要です。

## 起動方法

```
cd juku-app
node server.js
```

ブラウザで **http://localhost:3000** を開きます（`start.bat` をダブルクリックでも起動できます）。

## 画面の構成（区分ごとに別アプリ）

トップ（`/`）で区分を選びます。2つは**別々のログイン**として扱われ、同じ端末でも別ウィンドウで同時に開けます（ログインが混ざりません）。

| 区分 | URL | 利用者 |
|---|---|---|
| 講師・管理者用（管理画面） | http://localhost:3000/staff | 講師・教室管理者・システム管理者 |
| 生徒・保護者用 | http://localhost:3000/family | 生徒・保護者 |

- セッションはタブ／ウィンドウごとに独立（Cookie共有による役割の取り違えを防止）。
- 区分に合わないアカウントのログインは拒否されます（例：生徒IDで管理画面にはログイン不可）。

## ログイン（試験運用向けの仮アカウント）

各ログイン画面に体験用アカウントのボタンを表示します。パスワードは共通で **`lubo1234`**。

| 権限 | ログインID | 区分 |
|---|---|---|
| 生徒 | `s01`〜`s20` | 生徒・保護者用 |
| 保護者 | `g01`〜`g20` | 生徒・保護者用 |
| 講師 | `t01`〜`t10` | 管理画面 |
| 教室管理者 | `kanri` | 管理画面 |
| システム管理者 | `admin` | 管理画面 |

> 本番運用前に、各アカウントのパスワードは「アカウント設定」から変更してください。

## 実装済み機能（フェーズ1）

- **権限別ログイン**（生徒／保護者／講師／教室管理者／システム管理者）
- **権限別ダッシュボード**
  - 講師：本日の担当授業／本日の生徒／未入力の授業記録／欠席者／お知らせ
  - 生徒・保護者：次回の授業／宿題／欠席した授業の記録／お知らせ
  - 管理者：本日の授業数／出席予定者／欠席者／出勤講師／講師ごとの担当数
- **授業記録（欠席者カードの電子化）**
  - 授業記録の作成（生徒・日付・時限・科目・担当・出欠・進んだ内容・宿題・確認事項・コメント・添付名・次回予定）
  - 欠席時は生徒・保護者へ自動共有し、**確認状況（未確認／確認済み）** を記録
  - 一覧の検索・絞り込み（キーワード／科目／生徒／担当講師／確認状況）
- **入退室管理**（Comiru／wagaco／BitCampus EX を参考）
  - 講師・管理者が生徒の入室／退室を記録 → 生徒・保護者へ通知
  - 管理者は在室者を一覧・本日の在室人数を把握、生徒/保護者は本日の入退室状況を確認
- **通知の受信箱**：欠席共有・入退室などをまとめて表示、未読数をヘッダーに表示、既読管理
- **お知らせの既読管理**：未読バッジ・未読件数の表示、開封で既読
- **指導報告テンプレート（定型文）**：授業記録の入力をワンタップで補助（科目別＋共通）
- **生徒一覧・詳細／講師一覧・詳細／お知らせ／アカウント設定**
- 飯能教室のダミーデータ（生徒20・保護者20・講師10・管理者2・授業記録30・欠席含む）

## セキュリティ

- パスワードは `scrypt` でハッシュ化して保存（平文保存なし）
- Cookie セッションによるログイン管理
- すべての API で権限を確認し、権限の範囲内のデータのみ返却
  - 生徒は自分の情報のみ、保護者は自分の子のみ閲覧可能
  - 生徒の配慮事項など機密情報は管理者のみ閲覧可能
- 入力値の検証、リクエストサイズ制限、静的配信のパス制限、CSP 設定
- ログイン・個人情報の閲覧・授業記録の作成／確認などを監査ログに記録（個人情報の中身は残さず対象IDのみ）

## データの保存

`data/data.json` に保存されます。まだ現場入力が無い状態では、起動時に日付を当日基準へ寄せ直してダッシュボードが埋まるようにしています。実データが入力されると日付は移動しません。

初期化したい場合は `data/data.json` を削除して再起動してください。
