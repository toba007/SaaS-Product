## 現在の状況

MVP は動く状態まで来ています。

```
担当科目を登録 → 必要人数を入れる → 講師が希望を出す
→ 自動作成 → 盤面で確認・手直し → 確定 → 講師のスマホに出勤予定が出る
```

**時間割の構造についていただいた回答を反映しました。** いちばん大きい変更は、
「コマの時間帯は塾によって違う」という前提に作り替えたことです。

- 小学生 17:40-18:20 / 18:25-19:05、中学生 19:15-20:05 / 20:10-21:00 / 21:05-21:55 のように、
  **学年帯ごとに別の時間割**を登録できるようにしました
- 個別で1人が何人までみるかも、**塾ごとに登録**できるようにしました（1対4まで、など）
- 教室は個別に登録せず、**同時に使える数の上限**だけを持つ形に変えました

残っているのは、**必要人数（「火曜2限は英語2人」）をまだ管理者が手で入れている**ことです。
ここを生徒の受講予定から自動で出す（段階1）のが次の作業で、Q24 が決まれば着手できます。

## 1. いますぐ決めたいこと

**聞く相手：塾**

### Q36【最優先】開講する曜日・コマは、講師の希望を見てから決めていますか

**ここが合っているかで、作りの前提が変わります。** いま伺った理解を書きます。違っていたら教えてください。

いまのシステムはこう作ってあります。

```
クラスの時間割（中3英語Ⅰ＝毎週火曜2限）を管理者が登録する
  → その枠に講師を割り当てる
```

伺った内容はこうです。**依存の向きが逆です。**

```
【集団】中3英語にⅠ・Ⅱクラスがある（誰がどのクラスかは決まっている）
  → 担当できる講師がいつ来られるかを見る
  → 「英語は毎週火曜2限」と決める        ← ここが本当の仕事
  → 生徒に伝える

【個別】生徒に「どの科目を週に何コマ受けたいか」を聞く
  → 担当科目の講師の予定を見る
  → 「火曜2限に来てください」と伝える     ← 同じ仕事
```

**集団も個別も同じ形です。** 決まっているのは「量」だけで、
**「いつやるか」は講師の出勤可能から決めた結果**です。

これが正しければ、MVP の手順も順序が違います。

| | 手順 |
| --- | --- |
| いまの記述 | 担当科目 → **必要人数を入れる** → 希望を出す → 自動作成 |
| 実際 | 担当科目 → **希望を出す** → **開講を決める** → 必要人数が決まる → 自動作成 |

**希望の提出が、時間割を決めるより前に来ます。** 提出が学期ごと（Q31）なのと整合します。

確認したいことは3つ。

- 開講する曜日・コマは、**学期の頭に講師の希望を見てから**決めていますか
- **同じ生徒が2つのクラスを取っていたら重ならないように**していますか（中3英語Ⅰと中3数学Ⅱを同じ火曜2限にしない）
- **前の学期と同じ曜日を踏襲する**ことが多いですか、毎回組み直しますか

3つ目が「踏襲が多い」なら、**前学期のコピー＋差分修正**が一番効く機能になります。

**止まるもの：** 必要人数の自動算出（段階1）の作り方。
いまは「クラスの時間割は入力するもの」として作ってあるので、
出力として扱うなら画面と手順が変わります。

### Q33 クラスの分割は、どれくらいの頻度で起きますか

月半ばに1クラスを2クラスへ分けることがある、と伺いました。

- 年に何回くらい起きますか
- 分けたとき、**確定済みのシフトは今どうしていますか**（組み直す／その月は据え置いて翌月から）
- 分けた側の新しいクラスに入る講師は、どうやって決めていますか

**止まるもの：** 期の途中で必要人数が変わったときの手順。
いまは「確定を解除 → 必要人数を直す → 再作成（固定した割当は残る）」でできますが、
**現場が実際にどうしているか**に合わせないと、使われない手順になります。

### Q24【最優先】高校生の時間割は、中学生と同じか

いまは **「高校生ぶんの登録が無ければ、中学生と同じ枠を使う」** ようにしてあります。
同じ時刻のコマを中学生用・高校生用と二重に登録させると、入力が増えるうえに
「同じ時間に別のコマがある」状態になり、**同じ講師をそこに入れられなくなる**ためです。

| | 内容 | いまの動き |
| --- | --- | --- |
| **A. 中学生と同じ**（いまの前提） | 高校生も19:15から50分×3 | 登録不要。このまま動きます |
| B. 高校生だけ違う | 例：20:10から90分×2 | 「コマ・時間割」で高校生ぶんを登録すれば、そちらが使われます |
| C. 中学生と並行して別の時間で開ける | 同じ19:15に中学生と高校生を別々に開講 | 登録はできますが、**その2コマに同じ講師は入れません**（画面で警告が出ます） |

**止まるもの：** 高校生の受講予定。A か B なら今のまま進められます。

### Q25 週に何日開講していますか

いまは月〜土（日曜は休み）で仮置きしています。

- 休みの曜日はどこですか
- 曜日によってコマ数が変わりますか（土曜だけ昼から、など）

**止まるもの：** なし。ただし講師が希望を出す画面の大きさが変わります。

### Q26【重要】個別のコマ給は、みる人数で変わりますか

**個別の上限を4人にすると、給与の単価も 1対1・1対2・1対3・1対4 の4種類になります。**

- 実際に人数で単価が変わりますか。それとも個別は一律ですか
- 変わる場合、それぞれいくらですか

いまは**単価が入っていない形態で働くと0円で計算されます。** 上限を増やしたまま単価を入れ忘れると
給与が抜けるので、ここは運用前に必ず埋める必要があります。

**止まるもの：** 給与計算の正しさ。人数で変わらないなら、一律の単価を1つ入れるだけで済みます。

### Q27 特別授業は、どんなときに・どんなコマ割りで組みますか

期タイプとして枠は用意しました。テスト対策・入試直前・補講など、
**通常と違う時間で組むもの**があれば教えてください。

**止まるもの：** なし（後から登録できます）。

### Q23 生徒1人あたり、週に何コマ通うのが標準か

規模を見積もるために使います。「中学生は週2〜3コマ、高校生は週1〜2コマ」程度で構いません。
生徒数・講師数のおおよその規模も教えていただけると、**速度の確認をその規模で行えます。**

**止まるもの：** なし。性能テストの条件に使うだけです。

### Q35【保留】退職した講師の記録を、いつまで残すか

**いまは決めていません。無期限に残ります。** 消す仕組みも、期限で消える仕組みもありません。
リスクヘッジを検討するときに決める、として保留にしています。

退職にすると在籍から外れてログインもできなくなりますが、
**シフト希望・割当・打刻・コマ実績・給与・やりとりはすべて残ったまま**です。

決めるときは「全部まとめて◯年」にはできません。**記録の種類で向きが逆になります。**

| 記録 | 性質 | 目安 |
| --- | --- | --- |
| 打刻・コマ実績・給与 | **残す義務がある側** | 労働基準法109条で賃金台帳・出勤簿などは5年（経過措置で当分の間3年）。源泉徴収関係は税法で7年 |
| シフト希望・日ごとのやりとり | **消したほうがよい側** | 業務上不要になれば消す。個人の予定や事情が書かれている |
| 氏名・ログインID | 給与記録と紐づくため残る | 上の給与記録が残る間は消せない |

年数は一般的な枠組みです。**最終的な判断は塾側**で、顧問の社労士・税理士がいれば確認するのが確実です。

決めるのは3つ。

- 給与・勤怠の記録を何年残すか
- シフト希望とやりとりを何年で消すか（給与とは別に決められる）
- 期限が来たものを**自動で消すか、手で消すか**

**止まるもの：** なし（MVPには入れません）。ただし**本番運用の前に決める必要があります。**
1年目は退職者が少なく期限も来ないので急ぎませんが、
決めていないまま数年運用すると、消せない記録が溜まったまま判断を迫られます。

### Q17 学生チームの卒業後、誰が引き継ぐか

引き継げる人がいないなら、本番運用を始めるべきではありません。
